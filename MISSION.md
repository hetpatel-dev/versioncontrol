# Mission

**Learner:** Het
**Topic:** Git & GitHub
**Last updated:** 2026-06-25

## Why are you learning this?

To get a job as a developer. Git and GitHub are essential tools used at every software company — for version control, collaboration, and code review. Mastering them is a non-negotiable career skill.

## What does success look like?

- Can confidently use Git for daily development (commit, branch, merge, rebase, resolve conflicts)
- Can collaborate on GitHub (pull requests, code review, issues, forks)
- Understands Git's internals enough to recover from mistakes
- Can showcase work via a GitHub profile
- Job-interview ready on Git fundamentals

## What is out of scope?

- Git server administration (hosting your own Git server)
- Advanced internal plumbing (unless needed for deeper understanding)
- CI/CD pipelines (for now — may come later)

## Constraints

- Learning on Windows
- Using this repo as the sandbox
- Self-paced, session-by-session
