Git Commands — Quick Reference

Essential Git commands for daily use. [brackets] mean replace with your value.

Command What it does Example
git init Create a new Git repo in current folder git init
git status Show what's changed and what's staged git status
git add <file> Stage a file for commit git add index.html
git add --all Stage all changes (new, modified, deleted) git add --all or git add -A
git commit -m "msg" Create a snapshot with a message git commit -m "Fix login bug"
git log View commit history git log --oneline
git diff See unstaged changes (line by line) git diff
git diff --staged See staged (but not yet committed) changes git diff --staged
git config --global user.name Set your name for commits git config --global user.name "Jane Doe"
git config --global user.email Set your email for commits git config --global user.email "jane@example.com"

The Three States

  Working Directory    →    Staging Area    →    Repository (.git)
  (edit files)              (git add)             (git commit)

Pro tip

Use git log --oneline --graph --all for a visual tree of branches. We'll get to branches in a later lesson.
