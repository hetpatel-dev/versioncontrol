## What was learned

- Repeated add/commit cycle builds fluency with the three states
- `git restore --staged <file>` unstages a file (moves it from staging back to working directory)
- `git status` reliably shows what stage each file is in
- Commits appear in `git log --oneline` in reverse chronological order

## Why this matters

The add/commit cycle is the most frequent Git operation. Doing it repeatedly builds muscle memory. Discovering `git restore --staged` independently shows developing comfort with exploring Git's options.
