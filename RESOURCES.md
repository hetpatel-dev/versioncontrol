# Resources

High-quality, high-trust resources for learning Git & GitHub.

## Primary Sources

### Pro Git Book (by Scott Chacon & Ben Straub)
- **URL:** https://git-scm.com/book/en/v2
- **Type:** Book (free online)
- **Why:** The definitive reference on Git. Written by a co-founder of GitHub. Covers everything from basics to internals. Authoritative, well-explained, and freely available.
- **Used in lessons:** [coming soon]

### Git - The Simple Guide
- **URL:** https://rogerdudler.github.io/git-guide/
- **Type:** Article
- **Why:** A one-page quickstart that covers the essentials with minimal jargon. Great for reference after lessons.
- **Used in lessons:** [coming soon]

### GitHub Skills (official)
- **URL:** https://skills.github.com/
- **Type:** Interactive course
- **Why:** Official GitHub-hosted interactive learning paths. Browser-based, no setup required for some courses.
- **Used in lessons:** [coming soon]

### Oh My Git! (game)
- **URL:** https://ohmygit.org/
- **Type:** Interactive game
- **Why:** A card-game-style visualizer that teaches Git branching and internals through play. Excellent supplement.
- **Used in lessons:** [coming soon]

### Learn Git Branching
- **URL:** https://learngitbranching.js.org/
- **Type:** Interactive visualizer
- **Why:** The best interactive branching visualization on the web. Teaches complex branching/merging concepts through puzzles.
- **Used in lessons:** [coming soon]

### Atlassian Git Tutorials
- **URL:** https://www.atlassian.com/git/tutorials
- **Type:** Tutorial series
- **Why:** Well-structured, visual tutorials from the makers of Bitbucket. Good for complementary explanations.
- **Used in lessons:** [coming soon]

## Communities

### r/git on Reddit
- **URL:** https://reddit.com/r/git
- **Why:** Active discussion of Git workflows, problems, and best practices. Good for real-world wisdom.
- **Topics:** Git tips, troubleshooting, workflow discussions

### Stack Overflow (git tag)
- **URL:** https://stackoverflow.com/questions/tagged/git
- **Why:** The canonical Q&A for Git problems. Almost any error you hit has been asked and answered here.
- **Topics:** Troubleshooting, edge cases, configuration
