Viewing History — Quick Reference

git log options

CommandWhat it shows
git logFull commit history (author, date, message, hash)
git log --onelineOne line per commit (short hash + message)
git log --oneline --statFiles changed per commit (+/- counts)
git log --oneline --patchFull diff for every commit
git log --oneline --graph --allVisual branch tree
git log --oneline -3Last 3 commits only
git log --author="Name"Filter by author
git log --grep="fix"Search commit messages

Inspecting changes

CommandWhat it shows
git diffUnstaged changes (working directory vs staging)
git diff --stagedStaged changes (staging vs last commit)
git diff HEADAll changes (staged + unstaged) vs last commit
git diff <hash1> <hash2>Changes between two specific commits
git show HEADFull details of the latest commit (metadata + diff)
git show <hash>Full details of any commit

Undoing

CommandWhat it does
git restore <file>Discard unstaged changes (⚠️ permanent)
git restore --staged <file>Unstage a file (keep changes in working directory)
git commit --amend -m "new msg"Replace the last commit's message

Key: what HEAD means

HEAD is Git's way of saying "where you are right now." Usually it points to the latest commit on your current branch.
